# Unit economics

Track the system by cost per useful relationship and cost per accepted operational outcome—not raw node count.

Primary cost drivers:

- collector API calls and event throughput;
- normalization and identity-resolution compute;
- graph storage, indexes and temporal history;
- GraphRAG embeddings and model inference;
- retention, backups and evidence custody;
- connector maintenance and customer support.

Business value must be measured with controlled definitions: incident investigation time avoided, orphaned spend removed, migration dependency violations prevented, architecture-review time reduced and change failures avoided. Revenue exposure is prioritization context, not automatically realized loss or savings.

Before publishing ROI, compare baseline and post-adoption cohorts, record labor and platform costs, disclose confidence intervals and prevent double-counting across SRE, FinOps and migration outcomes.
