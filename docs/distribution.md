# Distribution roadmap

The adoption wedge is a useful offline CLI with one synthetic dataset and zero account requirement. Next, ship a GitHub Action that maps Terraform plans, followed by Kubernetes and Azure collectors, a Docker Compose graph backend and a Helm chart.

Community surfaces:

- versioned ontology and JSON Schema;
- connector SDK and conformance suite;
- OpenTelemetry Collector contribution path;
- Backstage entity processor;
- OpenCost allocation adapter;
- Terraform/OpenTofu plan action;
- MCP read-only query server;
- documented public evaluation datasets.

The hosted edition should sell operational scale, collaboration, history and support. It must not make the OSS engine intentionally unusable.
